# Staza Skill Tree – bisherige Entscheidungen

## Grundprinzipien

- Erfahrung zeigt, was der Nutzer bereits geleistet hat.
  - Beispiel:
    - 18 Flowlines gesammelt
    - 12 Places entdeckt
    - 850 km gefahren

- Skill Points bestimmen, wofür der Nutzer sich entscheidet.
  - Beispiel:
    - Rusher II ist freischaltbar
    - Adventurer II ist freischaltbar
    - Nutzer hat aber nur 1 Skill Point
    - Nutzer muss sich entscheiden, welchen Node er kauft

- Spezialisierung bestimmt die Reihenfolge, nicht die endgültige Identität.
  - Beispiel:
    - Nutzer investiert zuerst stark in Rusher
    - später kann er trotzdem Adventurer oder Endurance freischalten

- Progress-Werte werden nicht verbraucht.
  - Beispiel:
    - Node benötigt 15 Flowlines
    - nach Unlock bleiben die 15 Flowlines natürlich weiterhin erhalten

- Skill Points sind die eigentliche Währung des Skill Trees.
  - Beispiel:
    - Node benötigt:
      - Level 6
      - 15 Flowlines
      - 1 Skill Point

---

## Skill Points

- Skill Points entstehen primär durch Player-Level.

- Skill Points werden nicht bei jeder Fahrt vergeben.

- Skill Points sind knapp genug, damit echte Entscheidungen entstehen.

- Skill Points sind global.
  - Es gibt keine separaten:
    - Cycling Skill Points
    - Running Skill Points

- Beispiel:
  - Level 3 → +1 Skill Point
  - Level 5 → +1 Skill Point
  - Level 8 → +1 Skill Point
  - Level 11 → +1 Skill Point
  - später größere Abstände

- Node-Kosten können steigen.
  - Beispiel:
    - früher Node: 1 SP
    - fortgeschrittener Node: 2 SP
    - Prestige-/Cross-Sport-Node: 2–3 SP

- Skill Points sind nicht kaufbar.
  - Kein:
    - "Buy 5 Skill Points"
    - Premium-XP-Boost für schnellere Skill Points

---

## Progress / Requirements

- Kein gemeinsamer UI-Begriff wie "Mastery" nötig.

- Stattdessen werden konkrete Fortschrittswerte angezeigt.

- Beispiele:
  - 12 / 20 Flowlines
  - 7 / 10 Places
  - 2 / 3 Mountain Passes
  - 860 / 1000 km
  - Longest Ride: 82 / 100 km

- Requirements werden über mehrere Aktivitäten hinweg gesammelt.

- Requirements können sein:
  - XP / Level
  - Gesamtstrecke
  - Cycling Distance
  - Running Distance
  - Flowlines
  - Places
  - Mountain Passes
  - Viewpoints
  - Anzahl Activities
  - längste Fahrt
  - längster Lauf
  - Höhenmeter
  - verschiedene Collectible-Kategorien

- Beispiel:
  - Endurance II
    - Level 8
    - 750 km Cycling
    - längste Fahrt >= 60 km
    - 1 Skill Point

---

## Skill Tree Struktur

- Der Tree soll Multi-Sport langfristig unterstützen.

- Hauptäste nach Sportart sind sinnvoll.

- Beispiel:

  - Cycling
    - Rush
    - Adventure
    - Endurance

  - Running
    - Rush
    - Adventure
    - Endurance

  - später:
    - Hiking
      - Adventure
      - Endurance
      - evtl. eigene passende Unteräste

- Gleiche Spielstil-Zonen können sportabhängig unterschiedliche Anforderungen haben.

- Beispiel:
  - Cycling Rusher
    - Cycling Flowlines
    - Road-Cycling-Segmente
    - Distanz

  - Running Rusher
    - Running Flowlines
    - laufbare Segmente
    - Laufdistanz

- Flowlines dürfen sportartspezifisch sein.
  - Cycling Flowlines sind aktuell bewusst radspezifisch.
  - Später können Running Flowlines separat extrahiert werden.

---

## Cross-Branch Nodes

- Cross-Branch Nodes verbinden zwei Äste innerhalb einer Sportart.

- Beispiel:
  - Cycling Rush II
  - Cycling Endurance II
  - gemeinsam schalten sie "Breakaway Specialist" frei

- Sie belohnen Mischstile.

- Beispiel:
  - hoher Flow + hohe Ausdauer
  - daraus entsteht ein spezieller Hybrid-Node

---

## Cross-Sport Nodes

- Cross-Sport Nodes verbinden verschiedene Sportarten.

- Beispiel:
  - Cycling Adventurer II
  - Running Adventurer II
  - schalten "Multi-Sport Explorer" frei

- Mögliche Quest-Rewards:
  - an einem Tag Radfahren + Laufen
  - denselben Ort mit zwei Sportarten entdecken
  - Bike + Run Challenge
  - unterschiedliche Sportarten in einer Woche kombinieren

- Cross-Sport Nodes sind ein guter späterer Premium-Differentiator.

---

## Node-Kategorien

- Progression Node
  - klassischer Skill-Node
  - benötigt Level + Progress + Skill Point

- Quest Unlock Node
  - schaltet neue Quests oder Quest-Kategorien frei
  - Beispiel:
    - Fondo Quests
    - Flow Hunter Quests

- Feature / Utility Node
  - schaltet Funktionen frei
  - Beispiel:
    - High-Flow Map Filter
    - Undiscovered Places Filter
    - Endurance Segment Filter

- Cross-Branch Node
  - verbindet zwei Skill-Äste

- Prestige Node
  - spätere, teure Status-/Endgame-Nodes
  - Beispiel:
    - Century Rider
    - Ultra Explorer
    - Dual-Sport Veteran

---

## Quests und Skill Nodes

- Quests und Skill Nodes sind zwei getrennte Systeme.

- Ein Node wird nur durch:
  - Requirements
  - Skill Points
  freigeschaltet.

- Eine Quest ist nicht notwendig, um den Node selbst freizuschalten.

- Nodes können Quests freischalten.

- Beispiel:
  - Cycling Endurance III
  - Reward:
    - Fondo Quest Chain unlocked

- Quests können dann unabhängig abgeschlossen werden.

- Beispiel:
  - FONDO
  - Ride 100 km in one Activity

---

## Quest-Arten

- Quests dürfen wieder klare One-Ride-Challenges sein.

- Beispiele:
  - 3 Flowlines in one ride
  - 2 Mountain Passes in one ride
  - 100 km in one ride
  - 3 Flowlines + 1 Place in one ride

- Skill Tree Progress dagegen sammelt sich über viele Activities.

- Das ist die klare Trennung:

  - Skill Tree:
    - langfristiger Fortschritt

  - Quest:
    - konkrete Challenge

---

## Routine / Choice / Challenge

- Routine
  - normale Activities liefern:
    - XP
    - Progress Stats

- Choice
  - Skill Points bestimmen:
    - welchen Node der Nutzer zuerst freischaltet

- Challenge
  - bestimmte Nodes schalten anspruchsvollere Quests frei

- Beispiel:
  - Nutzer sammelt normal 15 Flowlines
  - bekommt durch Level einen Skill Point
  - kauft Rusher II
  - dadurch wird Flow Hunter Quest freigeschaltet

---

## Respec

- Zunächst kein Respec nötig.

- Der Tree ist nicht dauerhaft exklusiv.
  - langfristig kann man andere Äste nachholen

- Datenmodell sollte Respec später erlauben.

- Falls später nötig:
  - z. B. 1 Node Refund pro Tag
  - oder 1 kompletter Respec alle 7 Tage

- Kein täglicher kompletter Reset zum Start.

---

## Paid / Premium

- Basis-Progression bleibt auch für Free erhalten.

- Free Nutzer können weiterhin:
  - XP sammeln
  - Level steigen
  - Flowlines sammeln
  - Places entdecken
  - Distanz sammeln
  - Progress Stats aufbauen

- Skill Points sollten auch Free-Nutzern durch Level gewährt werden.

- Free Nutzer bekommen einen begrenzten Starter-Bereich des Trees.

- Premium schaltet frei:
  - vollständigen Skill Tree
  - Advanced Nodes
  - Cross-Branch Nodes
  - Multi-Sport Nodes
  - Prestige Nodes
  - Advanced Quest Chains

- Historischer Progress bleibt immer erhalten.

- Beispiel:
  - Free Nutzer fährt 1500 km
  - entdeckt 40 Places
  - erreicht Level 15
  - sammelt Skill Points
  - wird später Premium
  - kann die bereits verdienten Progress-Werte und Skill Points sofort verwenden

- Premium kontrolliert den Zugriff auf das Spielsystem, nicht die historische Leistung.

- Kein Pay-to-Win:
  - keine Skill Points kaufen
  - keine bezahlten Progress-Abkürzungen

---

## Node Rewards

- Wichtigster Reward:
  - neue Quests freischalten

- Weitere mögliche Rewards:
  - neue World Filter
  - neue Map Informationen
  - neue Segment-Informationen
  - neue Quest Chains
  - Cosmetics / Titles / Badges
  - Cross-Sport Challenges

- Beispiele:
  - Rusher II
    - Unlock "High Flow" Map Filter

  - Adventurer II
    - Unlock "Undiscovered Only"

  - Endurance II
    - Unlock "Long Endurance Segments"

  - Endurance III
    - Unlock Fondo Quest Chain

  - Multi-Sport Explorer
    - Unlock Bike + Run Challenges

- XP Multiplikatoren erstmal vermeiden.

---

## Zielbild

- XP zeigt:
  - wie viel der Nutzer generell gespielt hat

- Progress Stats zeigen:
  - was der Nutzer tatsächlich erlebt/geleistet hat

- Skill Points bestimmen:
  - wie der Nutzer seinen Tree entwickelt

- Nodes schalten frei:
  - neue Inhalte
  - neue Quests
  - neue Fähigkeiten/Filter

- Quests liefern:
  - konkrete Challenges

- Multi-Sport wird über:
  - separate Sport-Äste
  - gemeinsame Spielstil-Zonen
  - Cross-Sport Nodes
  verbunden

## Ergänzung: Free / Premium Grenze

- Tier 1 des Skill Trees ist vollständig kostenlos.

- Free Nutzer können:
  - alle Tier-1-Nodes sehen
  - alle Tier-1-Nodes freischalten
  - XP sammeln
  - Level steigen
  - Progress Stats sammeln
  - Skill Points verdienen
  - erste Quest-Kategorien erleben

- Ziel:
  - der Nutzer versteht das Skill-Tree-System vollständig
  - der Nutzer kann mehrere Richtungen ausprobieren
  - der Nutzer sieht, welche Spezialisierungen später möglich sind
  - Premium wird erst relevant, nachdem der Wert des Systems klar ist

- Premium beginnt ab Tier 2.

- Premium schaltet frei:
  - Tier-2+-Nodes
  - Cross-Branch Nodes
  - Prestige Nodes
  - Advanced Quest Chains
  - später Multi-Sport-Nodes

- Tier-2+-Nodes dürfen für Free Nutzer sichtbar sein.
  - Anforderungen können angezeigt werden
  - Rewards können angezeigt werden
  - Unlock ist jedoch Premium vorbehalten

- Free Nutzer sammeln weiterhin alle relevanten Progress-Werte für spätere Nodes.
  - Beispiel:
    - 40 Flowlines
    - 1.500 km
    - 20 Places
    - Level 15
  - diese Leistungen gehen nicht verloren

- Free Nutzer verdienen weiterhin Skill Points.
  - ungenutzte Skill Points bleiben erhalten
  - bei späterem Premium-Abschluss können sie sofort eingesetzt werden

- Premium kauft keine Leistung.
  - keine kaufbaren Skill Points
  - keine XP-Booster
  - keine Abkürzung von Requirements

- Premium schaltet Zugriff auf tiefere Progression frei, nicht den zugrunde liegenden Fortschritt.

## Ergänzung: Skill-Point-Kurve

- Bis etwa Level 30 sollen ungefähr 10 Skill Points verdient werden.

- Vorgeschlagene Vergabe:
  - Level 1 → 1 SP
  - Level 3 → +1
  - Level 5 → +1
  - Level 8 → +1
  - Level 11 → +1
  - Level 14 → +1
  - Level 18 → +1
  - Level 22 → +1
  - Level 26 → +1
  - Level 30 → +1

- Zweck:
  - frühe Entscheidungen kommen schnell
  - später werden Skill Points merklich wertvoller
  - nicht alle verfügbaren Nodes können sofort gekauft werden

- Node-Kosten:
  - Tier 1 → 1 SP
  - Tier 2 → 1–2 SP
  - Tier 3 → meist 2 SP
  - Prestige / Cross-Sport → 2–3 SP
